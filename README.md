# Intentional MVP

Deploy to Vercel, then add to your phone home screen.

## Deploy

1. github.com/new - create repo
2. Click "uploading an existing file"
3. Unzip, select ALL files inside, drag into GitHub
4. Commit
5. vercel.com - Add New Project - import repo - Deploy

## Install on Phone

iPhone: Open URL in Safari - Share button - Add to Home Screen
Android: Open URL in Chrome - Menu - Add to Home screen
